Les points essentiels

Objectif

Un widget Android 4×2 indépendant pour les transferts de FMP : Favoris, Offres reçues, Mes offres, Offres en attente. Pas de recherche sur le marché général. Pas d’enchère automatique.

Statut de la V2.1

L’APK et les sources sont joints ; les tests automatiques ont passé. Les captures réelles confirment les étapes V1.2 à V2.0. Le correctif V2.1 doit encore être confirmé sur le téléphone.

Fonctionnement Firefox

Le userscript lit les cellules HTML et transmet les relevés au pont privé 127.0.0.1:28471. Ce n’est pas une connexion serveur FMP en arrière-plan.

Fonctionnement application FMP

La lecture OCR repose sur une capture volontaire de l’application. Cette partie validée n’a pas été modifiée fonctionnellement en V2.1.

Comptes à rebours

L’heure de fin est estimée à partir d’un délai lu à une heure donnée. Elle diminue localement, mais FMP peut arrondir les durées.

Confidentialité

Clé locale privée pour le pont Firefox, aucune capture enregistrée dans le ZIP, pas de mot de passe FMP. Ne publie jamais la clé de liaison.

Correction critique du script

Le workflow de publication V2.1 copie par erreur le script V2.0 sous le nom V2.1. Utilise le script V2.1 CORRIGE inclus ici.
